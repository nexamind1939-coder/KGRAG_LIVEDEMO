# KGRAG_LIVEDEMO

## Simple Knowledge Graph RAG with Neo4j

A beginner-friendly implementation of a Knowledge Graph Retrieval-Augmented Generation (Graph RAG) system using Python, LangChain, and Neo4j Aura.

### Overview
This project demonstrates how to build a Knowledge Graph by extracting entities and relationships, storing them in Neo4j, and retrieving connected information through graph queries.

### Technologies
- Python
- LangChain
- Neo4j Aura
- Cypher Query Language
- NetworkX

### Key Concepts
- Knowledge Graph construction
- Nodes and relationships
- Graph database connectivity
- Cypher queries
- Graph-based information retrieval

### Objective
To understand how Knowledge Graphs enhance RAG systems by connecting related entities and providing context-aware information retrieval.
